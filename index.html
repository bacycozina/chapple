🍎 차플게임 플레이 방법

사과의 숫자를 더해 10을 만들고, 콤보를 이어 높은 점수에 도전하세요!

🖱️ 이렇게 플레이해요

  1. 사과판을 처음 클릭하면 120초 타이머가 시작돼요. 시작 전에는 천천히 살펴봐도 돼요.
  2. 마우스 왼쪽 버튼을 누른 채 드래그해 직사각형으로 사과를 선택하세요. 선택 영역에 조금이라도 닿은 사과가 포함돼요.
  3. 위쪽의 선택 합이 10일 때 마우스를 놓으면 사과가 사라져요. 예: 3 + 7, 2 + 3 + 5.
  4. 빈칸을 포함해 선택해도 돼요. 합이 10이 아니면 사과는 그대로이고 점수는 깎이지 않아요.

🔥 콤보는 빠르게 이어가요

한 번 성공하면 1콤보! 아래 시간 안에 다시 성공하면 콤보가 올라가요. 게이지는 다음 성공까지 남은 시간이에요.

현재 콤보다음 성공까지 제한시간
1~10콤보10초부터 1콤보마다 1초씩 감소
9·10콤보는 2초
11~20콤보11콤보에서 다시 5초!
매 콤보 약 0.33초씩 줄어 20콤보는 2초
21콤보 이후2초 고정

제한시간이 지나면 콤보가 0으로 돌아가요. 실패한 선택은 콤보를 바로 끊지는 않지만 시간은 계속 흘러요.

✨ 점수와 보너스

  • 사과 1개 제거 = 기본 1점. 숫자의 합이 점수가 되는 것은 아니에요.
  • 10·20·30…콤보마다 파란 불꽃! 달성한 선택의 점수 계산 후, 10초 동안 점수가 ×2가 돼요. 다시 달성하면 남은 시간이 10초로 갱신돼요.
  • 100점마다 제한시간 +20초. 200점, 300점에서도 계속 받아요.

🎒 클리어하면 아이템을 받아요

남은 사과로 만들 수 있는 합 10 직사각형이 하나도 없으면 클리어예요. 사과를 모두 없앨 필요는 없어요! 클리어하면 아래 아이템 중 하나를 무작위로 1개 받아요.

  • 🍇 점수 ×1.5: 10초 동안 획득 점수 1.5배. 파란 불꽃과 겹치면 ×3! 0.5점 단위 점수도 생겨요.
  • ❄️ 시간 동결: 10초 동안 게임 제한시간만 멈춰요. 콤보와 다른 아이템의 시간은 계속 흘러요.
  • 🍊 조합 연결: 10초 동안 가능한 조합을 최대 3개까지 주황색 과일로 표시해요. 모두 한꺼번에 선택하지 말고, 선택 합 10을 확인하세요.

아이템은 보유한 상태에서 게임을 시작한 뒤 버튼을 눌러 사용해요. 같은 아이템을 다시 쓰면 1개를 소모하고 효과가 10초로 갱신돼요.

🔄 게임 종료와 다시하기

제한시간이 0이면 게임이 끝나요. 다시하기는 점수·시간·콤보·게임판을 초기화하지만 보유 아이템은 유지해요. 페이지를 새로고침하거나 닫으면 보유 아이템도 초기화돼요.

도움말을 읽는 것만으로는 게임이 시작되지 않아요. 다만 이미 시작한 게임은 도움말을 열어도 시간이 계속 흘러요.
